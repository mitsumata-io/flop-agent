# Contributor and automation guidance

This public repository contains offline research tools and participation documentation.

- Use Python 3.10+ and the standard library for the current tools.
- Keep calculations deterministic and validate nonnegative, finite inputs and bounded fractions.
- Run `python -m unittest -v` and `python verify_project.py` for relevant changes.
- Document reproduction commands and distinguish hypothetical inputs from observed FLOP activity.
- Cite dated primary sources for protocol claims and preserve unresolved requirements explicitly.
- Do not claim that tests or repository completeness establish an airdrop entitlement.
- Keep credentials, signing material, private data and local backups out of the repository.
- The existing public identity records are reference material; do not change them as part of unrelated edits.
- Follow SECURITY.md for vulnerability reporting and CONTRIBUTIONS.md for evidence standards.
