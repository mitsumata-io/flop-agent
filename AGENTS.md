# Project instructions

## Scope

This is Mitsumata's independent FLOP research and agent-development repository. Make claims proportional to the evidence. Distinguish proposals, working implementations and observed live behavior. Record dates and source versions for protocol-dependent work.

## Private material

Never read, list, search or traverse signing or wallet directories outside this public project. Respect every private location the operator has excluded from access, including the previous project's signing directory.

The new identity is created by the user in a separate private local folder. Treat that folder as outside normal agent access. Do not read or print its private key or ask the user to paste a seed, key or passphrase. Public DID records may be supplied separately by the user.

Do not put private keys, encrypted private-key files, passphrases, seed values, environment credentials or signing backups into this repository. Ignore rules are not permission to inspect secrets.

## Participation

Do not manufacture activity, participation scores or reward claims. A fresh identity does not establish a new entitlement or erase prior participation. Record the retirement of earlier project activity honestly when relevant. Do not operate multiple identities to seek duplicate benefits.

## Publications and state changes

Follow the user's authorized scope. Do not post messages to Technocore, X or project maintainers merely because a local document describes a future step. Obtain authorization for the intended destination and message purpose when it has not already been given.
